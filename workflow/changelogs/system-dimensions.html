Changelog

2026-11-04 — K2 server + battle engine (D chat 2026-11-04; manager defaults D 2026-11-04 "decide yourself"; dfmc-client lane K2, spec docs/dimension-keys-2026-11.md). On dev. The server sells, spends and runs the keys: /api/shop/buy grants a key row into a server ledger (dim_key_ledger, paid, never an item: no trade, dismantle or export) in the same step as the 20 Wraithgold debit; GET /api/floor/dim, POST /api/floor/dim/enter|fight|loss|leave and POST /api/battle/dim/win own the one live run per account (enter spends the key; five floors of five battles in order; each credited win pays the floor's Reward_<Resource> and party / soul / class XP at the ordinary per-kill rate, nothing else; death or leaving answers ret, the floor the player stood on, clamped to their progress; a replayed win answers the same and pays once; a win under Min_Battle_Ms is 429). Encounters are a pure function of a server seed (src/dimension.js). Engine (src/battle_round.js / src/battle.js, play/battle_module.js rebuilt): Enchanted Haste acts first (only a class ultimate before it); Inscribed Writ halves debuffs on it, doubles its buffs and doubles the debuffs it inflicts (knobs ride the chip; half-up, min 1 turn); a signature chip is never read as a debuff, so a cleanse can no longer strip Rust Fury / Sanguine Ward. Swollen floor 5 eased (manager default): dimension_floors.csv gains a Key_ID column; a row carrying one is a sparse per-dimension override (empty cell = the shared row). DK-ESSENCE floor 5 fights Common quality + Uncommon gear: a level-90 party wins 60% of those battles (was 40%; tools/sim_dim.mjs, 20 seeds), the other four dimensions unchanged. The page's floor-5 bindings now name the shared row (Floor=5&Key_ID=) - binding only, the text did not move. Shop rows SHOP-006–010 stay Enabled 0 until the client (K3) ships. Gates: tools/probe_dim_server.py (local worker, D's save), tools/probe_dim_engine.mjs. At release: system-dimensions.html says the dimensions are open (not "coming soon") and the floor-5 row notes the Swollen Dimension fights lighter gear (Common quality, Uncommon gear) — applied with K3.
