The law itself, researched: Music and Sound Effects keep (pct/100)^1.6, which is Stevens’ power law — the slider is percent of full loudness: 50% is half as loud (−9.6 dB), 30% is −16.7 dB, 10% is −32 dB, 0 is silence — the curve that the square, cube and dB-linear sliders of other titles approximate, and the one that keeps 30% clearly audible. Banner, lead, closing note

Live in game — the tables follow SETTINGS_SCHEMA in play/app.js

The in-game Settings menu. One full-screen panel with a section rail on the left and options on the right (mobile: sections collapse into an accordion). Every option persists locally and syncs with cloud save. Defaults are chosen for a first-time mobile player.

All values persist to local settings storage immediately and ride along with cloud save. Per-section "Restore Defaults" resets only the visible section. Nothing in Settings can grant gameplay advantage; PvP pacing is server-controlled.

Layout

  • Opened from the gear icon on the main HUD. Full-screen overlay, dark parchment-and-iron chrome consistent with the codex aesthetic.
  • Section rail (left, Cinzel labels): Audio · Display · Battle & Autoplay · Controls · Tutorials · Notices · Notifications · Account & Data · Language & Accessibility · Legal & Support.
  • Control types: slider (0–100), toggle, segmented (2–4 exclusive choices), dropdown, action button (opens dialog/page).
  • Footer bar: Restore Defaults (per open section, with confirm) and game version/build string.
  • Changes apply instantly — no Save button. Destructive actions always confirm.

Controls

Status: LIVE on release since 2026-09-02 (0.67). Keyboard only — a touch device has no keys to bind, and the section changes nothing there.

OptionControlValuesDefault
Toggle AutoplayKeyany single characterA
Open / Close EquipmentKeyany single characterE
Open / Close InventoryKeyany single characterI
Lock / Unlock HoveredKeyany single characterL

Click a row to arm it, then press the key. Clicking the armed row again, or Escape, cancels; Backspace or Delete unbinds (the row prints an em dash and matches no key). Space never binds. Closing Settings drops an armed row without binding anything. One key belongs to one action: binding a key another row already uses takes it from that row.

The rule. A bound key calls the same thing the on-screen button calls, so the keyboard can never reach a state a click cannot. A key is ignored while a text field has focus, while Ctrl / Cmd / Alt is held (browser shortcuts win), on auto-repeat, and at character creation. Inventory opens the item bag; with the soul bag already open it switches to the item bag rather than closing.

Lock / Unlock Hovered (SHIPPED IN 0.87, 2026-09-28): with the pointer over a creature or item tile in either bag, the key toggles that record’s lock — the same LOCK the detail panel and creature sheet toggle, ignored by every dismantle. It does nothing when the pointer is off the tiles, while a panel covers the bag, or in dismantle-select mode.

NEW badge (SHIPPED IN 0.87, 2026-09-28; a bag display rule stored here): a creature or item that arrives in a bag — a hatch, a drop, a craft — wears a red dot and NEW at the bottom left of its tile until the pointer passes over it (a tap on touch). Records moving between the bag, the equipment slots and the pens are not arrivals, and what a load brings is the baseline, never an arrival. The unseen set is a list of uids in this per-realm settings store (bag.fresh), pruned when a uid leaves; Restore Defaults does not touch it.
